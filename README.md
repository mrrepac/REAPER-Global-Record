# REAPER Global Record

Расширение для Windows x64 позволяет управлять записью в REAPER из Obsidian или другого приложения. Оно загружается вместе с REAPER.

[Скачать расширение для Windows x64](https://github.com/mrrepac/REAPER-Global-Record/releases/latest/download/REAPER-Global-Record-Windows-x64.zip)

В конце главной панели REAPER появляется кнопка со значком компьютерной клавиатуры и подсказкой «Глобальные клавиши записи». Нажми её, чтобы включить или выключить оба сочетания. Подсветка означает, что сочетания включены. REAPER запоминает выбор между запусками. При первом запуске сочетания включены, если они свободны.

Открой проект в REAPER, выбери вход микрофона и включи красную кнопку записи на вокальной дорожке. Переключись в заметку с текстом.

| Сочетание | Действие |
| --- | --- |
| Ctrl+Alt+R (К на русской клавиатуре) | Начать запись. Во время записи — остановиться и удалить текущий проход со всех записывавшихся дорожек |
| Ctrl+Alt+Пробел | Завершить запись и сохранить дубль. REAPER останется на месте до ручного запуска прослушивания. Во время воспроизведения — остановить его |

Если сбился, нажми Ctrl+Alt+R один раз, чтобы отбросить дубль. Чтобы сразу переписать, нажми ещё раз. Можно держать Ctrl и Alt и нажимать только R. Удержание самой R считается одним нажатием. Если ни одна дорожка не подготовлена к записи, при попытке старта прозвучит системный сигнал Windows.

## Установка

1. Скачай ZIP-архив по ссылке выше.
2. В REAPER открой **Options → Show REAPER resource path in explorer/finder**. Оставь эту папку открытой и закрой REAPER.
3. Распакуй содержимое архива в открытую папку. Файл `reaper_global_record.dll` окажется в `UserPlugins`, а значки — в `Data\toolbar_icons`.
4. Запусти REAPER. В конце главной панели появится кнопка с клавиатурой.

Проверено в REAPER 7.86 для Windows x64. Чтобы удалить расширение, закрой REAPER и удали `UserPlugins\reaper_global_record.dll` и файлы `toolbar_global_record_keys.png` из `Data\toolbar_icons` и её подпапок `150` и `200`.

## Сборка

Запусти `build.cmd` при установленных Visual Studio Build Tools с компонентами C++ x64 и Windows SDK. Готовое расширение появится в `build\reaper_global_record.dll`.

Использованы заголовки Cockos [REAPER Extension SDK](https://github.com/justinfrankel/reaper-sdk/tree/61cc0d4ada1e4d8438186ed8ba5e5f9d72b148b9/sdk). Запись и завершение дубля выполняют встроенные действия REAPER 1013, 40667 и 40668.
